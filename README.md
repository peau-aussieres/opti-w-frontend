# Opti-W Ambassadeur - Frontend

Application React pour la plateforme de parrainage Opti-W, spécialisée dans la vente de lunettes de soleil et de vue au Canada.

## 🚀 Fonctionnalités

- **Interface moderne** avec Tailwind CSS
- **Système de parrainage** pour les clients Opti-W
- **Calculateur de gains** en dollars canadiens
- **Pages responsive** pour tous les appareils
- **Navigation intuitive** entre les différentes sections

## 🛠️ Technologies

- **React 18** - Framework frontend
- **Tailwind CSS** - Framework CSS utilitaire
- **React Router** - Navigation côté client
- **Vite** - Outil de build moderne
- **Lucide React** - Icônes modernes

## 📦 Installation

```bash
# Cloner le repository
git clone https://github.com/peau-aussieres/opti-w-frontend.git
cd opti-w-frontend

# Installer les dépendances
npm install

# Lancer en mode développement
npm run dev

# Construire pour la production
npm run build
```

## 🌐 Déploiement
